# Label triage

Các skill nói chuyện bằng năm vai trò triage chuẩn. File này ánh xạ các vai trò đó sang chuỗi label thực tế dùng trong issue tracker của repo này.

| Vai trò chuẩn trong skill | Label trong tracker của mình | Ý nghĩa                                       |
| ------------------------- | ---------------------------- | --------------------------------------------- |
| `needs-triage`            | `needs-triage`               | Maintainer cần đánh giá issue này             |
| `needs-info`              | `needs-info`                 | Đang chờ người báo cáo bổ sung thông tin      |
| `ready-for-agent`         | `ready-for-agent`            | Đã đặc tả đầy đủ, sẵn sàng cho agent AFK      |
| `ready-for-human`         | `ready-for-human`            | Cần người làm                                 |
| `wontfix`                 | `wontfix`                    | Sẽ không xử lý                                |

Khi một skill nhắc tới một vai trò (vd "gắn label triage sẵn-sàng-cho-AFK"), dùng chuỗi label tương ứng trong bảng này.

Sửa cột "Label trong tracker của mình" cho khớp với bộ từ vựng bạn thực sự đang dùng.
